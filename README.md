📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Zomato dataset to understand restaurant trends, customer preferences, pricing patterns, and ratings distribution.

The main objective is to extract meaningful insights from raw data using visualization and statistical techniques.

🎯 Objectives:
   - Understand the structure of the Zomato dataset
   - Clean and preprocess the data
   - Analyze restaurant ratings and pricing
   - Identify popular cuisines
   - Study online delivery and table booking trends
   - Visualize important patterns using graphs
